POLLAPP - SUPABASE EINRICHTUNG

1. Öffne dein Supabase-Projekt.
2. Links auf SQL Editor -> New query.
3. Öffne SUPABASE_SETUP.sql aus diesem Projekt, kopiere alles hinein und klicke Run.
4. Danach lokal im Projektordner: npm install, npm run build, npx ng serve.
5. Prüfe F12 -> Console. Der alte ERR_NAME_NOT_RESOLVED zur alten Supabase-URL sollte weg sein.

Hinweis: Die environment.ts ist bereits auf dein neues Supabase-Projekt und deinen Publishable Key eingestellt.
